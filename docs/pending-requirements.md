# ForgeLoop 待实现需求列表

日期：2026-10-22。列表只记录**尚未实现或尚未验证**的事项，不构成首版验收门槛；进入列表
不等于已承诺排期。当前范围以[产品需求](product-requirements.md)与[状态记录](status.md)为准。

## 1. 选择规则

每次只选择能解决当前重复痛点的一项，明确目标、依赖与验收。先完成真实业务闭环，再决定是否
扩展到渠道、平台或生产运维；不为尚未接入的场景提前建平台。

## 2. 近期（P1，直接影响当前闭环可信度）

| ID | 事项 | 触发条件 | 验收要求 |
| --- | --- | --- | --- |
| N01 | 真实长跑与恢复验证 | 需要证明断开客户端、宿主重启、停止/取消在真实模型下成立 | 可重复脚本：受理后断开、重启找回 pending、claimed 标 unknown 且不重放、停止取消在途 Agent、记录可核对；保留原始日志 |
| N02 | 覆盖率门槛 | 需要防止关键规则回退 | vitest coverage 接入并设阈值；未达标即失败，不用提示代替 |
| N03 | 变异测试 | 需要验证测试能发现规则被削弱 | 选定 TypeScript 变异工具，覆盖批准/额度/请求领取等关键规则；夜间运行 |
| N04 | 依赖审计 | 安装包依赖进入分发 | 接入 `npm audit` 或等价工具；例外须登记复查条件 |
| N05 | 格式化器 | 多人/多 Agent 并行编辑 | 选定 Prettier 或等价工具；`make format` 真正可用并纳入检查 |
| N06 | 桌面 profile 安装 | 所有者要在日常 DSH 中使用 | 在非受限环境把候选包安装到目标 profile，重启后验证命令/工具与记录；保留 V0 恢复路径 |
| N07 | 候选 diff 的可重放基线 | 交付后源码继续变化时 diff 可能无法应用 | 证据中保存基线快照或提供三方合并；应用失败必须显式阻断而不是猜测 |

| ID | 事项 | 说明 |
| --- | --- | --- |

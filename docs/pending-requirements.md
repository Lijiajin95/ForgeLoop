# ForgeLoop 待实现需求列表

日期：2026-10-12，Asia/Shanghai。状态：**全部待实现；不构成首版验收门槛**。

来源包括此前 grill 的完整目标和本次快速启动审查。完整旧规则保存在 [历史快照](history/full-product-scope-2026-10-12.md)，审查理由见 [需求审查](requirements-review.md)。进入列表不等于已承诺排期；首次实施只按 [首版范围](product-requirements.md)。

## 1. 选择规则

每次只选择能解决当前重复痛点的一项，明确目标、依赖与验收。先完成首版的真实任务，再决定是否需要 P1；P1／P2 是推进建议，不是全量必做清单。生产自动化所需保护在生产需求开始时补齐，不为尚未接入的生产系统提前建平台。

## 4. 首版必须已经有的基础

以下能力不会通过后置清单省略：明确项目与任务身份、执行前批准、独立工作区／容器、PI 原始记录、真实测试输出、独立审查、人工验收、工时限制、研发每次三失败轮次及追加记录、main 保护、现场默认保留。

本机硬盘的简单手动备份是首版操作步骤；B13 后置的是持续备份与复杂恢复保证。CLI 停止与中断标记是首版基础；B08、B12 后置的是可恢复暂停和自动恢复。

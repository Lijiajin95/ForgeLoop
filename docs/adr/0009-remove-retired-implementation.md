# ADR 0009：删除退役实现与未接入运行链路的重复代码

- 状态：已接受（2026-10-28，所有者要求根据最新项目文档删除冗余功能和代码）
- 依据：[统一方案 §5](../product.md#5-宿主协调与多-agent-流程)、[§6](../product.md#6-全新存储与一致性协议)与[§14](../product.md#14-实施边界与待决项)
- 接续：[ADR 0008](0008-typescript-native-dsh-plugin.md)；实际范围和验证见[清理记录](../status.md#13-冗余功能与代码清理2026-10-28)

## 背景

当前产品使用 TypeScript 原生 DSH 插件。旧 Python 核心、自建网页、邮件、独立服务、固定启动器、
配置及工作流已退役，仍在 `legacy/` 保存整套源码与测试。根目录的旧安装脚本还依赖已移除的
Python 工程与 systemd，容易被误当作当前安装入口。

活动源码另有只由测试调用的内存批准簿、材料绑定、阶段路由、产物草稿校验和 worktree API。
真实批准、推进、验收和工作副本分别由任务包规则、运行时、记录层与快照路径承担，
这些孤立实现的测试不能证明实际动作入口已强制相应规则。

## 决定

1. 删除工作树内的退役快照与旧安装脚本，保留 Git 历史及真实业务证据。
2. 删除经引用核对无活动调用的重复实现与专用测试；保留实际调用的规则、任务记录类型和摘要计算。
   将重复正式测试文件的独有反例合入活动测试，候选 diff 测试使用实际快照路径。
3. 在架构契约中登记已清理的仓库路径，由确定性检查拒绝重新引入；覆盖通过与拒绝两侧。
4. 快照按 Git 跟踪和忽略规则选择文件，移除针对退役目录名称的特判，保留受管项目的未提交进展。
5. 当前 `/fl` 与旧库兼容仍在运行链路使用，保留到新决定入口和存储方案完成替代及验证时再迁移。
   本批不改变生效授权、失败计数、限额、停止或材料准入规则。
   后续：2026-10-28 的所有者要求已由 [ADR 0010](0010-remove-command-surface-legacy-compat-and-commit-policy.md)
   删除上述命令表面与旧库兼容；本项不再是当前状态。

## 后果与回查

仓库和候选包只维护当前实现；不再保留可直接运行的旧路线副本。退役文件清理前均与
`b344b5a08407f0f94ab5d3ca90887ecf17a24e7f` 一致，可按原路径回查，例如：

```sh
git show b344b5a08407f0f94ab5d3ca90887ecf17a24e7f:legacy/python/src/forgeloop/cli/serve.py
git show b344b5a08407f0f94ab5d3ca90887ecf17a24e7f:scripts/install_local_service.sh
```

历史库、候选、轨迹和部署记录继续保留。旧目录遗留的本机 Python 字节码先移入本批缓存备份，
不作为活动源码或交付证据。新方案的独立子运行时、自主交付、工作台决定和全新存储仍需实施，
本次清理不构成这些能力已经完成的结论。

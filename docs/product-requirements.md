# ForgeLoop 首版产品需求：TypeScript 原生 DSH 插件

日期：2026-10-22，Asia/Shanghai。状态：**范围已冻结**。旧 Python 首版需求（V0-01…V0-10）的
历史记录保留在 Git 与 `legacy/` 快照中，不再作为当前实现依据。实现与验证状态见
[状态记录](status.md)，不写在本文件。

首版目标：**在 DSH 中完成一条真实研发闭环——提交需求、分析、规划、人工批准、实现、独立
审查、正式测试、候选打包、人工验收，并用它改进插件自身。**

## 1. 用户与范围

一名所有者、一个专用 DSH profile、一个项目、一次推进一条需求。DSH 是唯一需要单独启动的
常驻宿主；不提供独立网页、`forgeloop serve`、热升级启动器或第二套常驻服务。

首版输入为文本需求。大需求人工拆成任务；不做任务树、多租户、远程访问、邮件/IM、发布部署。

## 2. 必须实现的需求

| ID | 必要能力 | 完成要求 |
| --- | --- | --- |
| PR-01 | 插件装载与配置 | 可作为 npm bundle 安装到 DSH profile；非法配置装载时失败；记录根、项目、模型选择明确 |
| PR-02 | 需求受理与修订 | 先落库再返回稳定身份；版本 1 为原文，修订只追加；同幂等键同内容复用、不同内容拒绝 |
| PR-03 | 结构化分析 | 无工具 Agent 输出并校验目标、场景、验收标准、待澄清项；有待澄清项时不进入实现 |
| PR-04 | 任务包与批准 | 任务包含文件清单、验收、正式测试命令、依赖；批准绑定需求版本与任务包版本；旧批准不得驱动新版本 |
| PR-05 | 真实实现 | 由真实 DSH Agent 在独立快照副本中修改代码；不得改产品主工作树或创建产品提交 |
| PR-06 | 独立审查 | 新会话、无工具、独立目录，针对固定候选 diff；结论结构化，畸形 fail-closed |
| PR-07 | 正式测试 | 程序运行批准的 argv，保存命令、退出码、耗时与日志；模型自评不算通过 |
| PR-08 | 有界修复与授权 | 测试失败每轮计一次且幂等；每次授权最多三个失败轮次，追加不清零；额度用尽等待决定 |
| PR-09 | 持久工作与恢复 | 请求先落库；原子领取、重复唤醒去重；重启把未收口请求标 unknown、动作标 interrupted；停止生效且不盲重放 |
| PR-10 | 候选包与验收 | 从已交付 diff 构建并打包，记录 SHA-256 与文件清单；验收绑定实际材料；材料变化即失效 |
| PR-11 | 查询与证据 | 命令与只读工具可查状态、方案、证据、请求；结果含对象、版本与决定效果 |
| PR-12 | TypeScript 工具链 | 活动实现、测试、契约与提交策略校验均为 TypeScript；`make check` 可执行；旧 Python 不参与运行 |
| PR-13 | 自迭代 | V0 受理一项真实自身改进需求，经批准、实现、审查、测试得到 V1 候选包；安装后在 V1 中验证新行为并回查历史 |
| PR-14 | 安装与恢复 | 提供本地候选包、安装／重启步骤、V0 安装包与记录副本；恢复不依赖损坏的 V1 |

## 3. 交互要求

- 人类入口为 `/fl` 命令；批准、验收、推进、追加授权、停止、取消只从这里进入，结果明确显示
  需求身份、任务包版本、材料摘要与决定效果。
- 模型工具只做只读查询与需求受理；不得批准、验收、推进或自证 owner。
- 首版使用 DSH 原生会话、命令结果与工具卡片；不自建聊天壳、不嵌入旧网页、不做主题布局。

## 4. 非目标（本轮明确不做）

- 多租户、公开分发、Plugin Market 上架、许可与商业化；
- 邮件／IM／移动端等额外渠道；
- 发布、部署、回滚与生产运维平台；
- 容器化或 OS 级审查隔离；
- 数据库引擎更换、远程服务形态、LangGraph.js 或通用 Agent Runtime 重建；
- 为兼容旧命令保留整套 Python／前端工具链。

## 5. 验收基线

1. 在无 Python 解释器、无旧 `.venv` 的环境中，能安装、构建、检查并完成插件主流程。
2. 从 DSH 插件入口提交需求，经真实 Agent 开发、独立审查与正式测试，结果可在 DSH 回查。
3. 关闭客户端后宿主继续推进；重启找回 pending；重复触发去重；未知动作先核对；停止生效。
4. V0 推进自身改进得到 V1；V1 新行为可用、历史可读，保留 V0 恢复入口。
5. 过期批准、材料变化、重复消费、停止后再启动等拒绝行为有行为测试与真实证据。
6. 实现、文档、契约、安装包与实际运行版本一致；未执行或未验证事项如实标记。

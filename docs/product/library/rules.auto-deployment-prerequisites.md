# 自动部署的最低前置条件

## 业务目标
让自动执行不降低安全门槛，失败时仍有可恢复与可通知的路径。

## 用户与角色
- 所有者
- 主控
- 部署工具

## 触发与前提
把某个部署目标配置为自动审批，或评估该目标能否自动执行

## 预期行为
不满足任一条件的目标在配置阶段即被拒绝，不会被自动执行。

## 业务规则
- 必须保留至少一份可回退位置。
- 必须有可用的告警去处，重载失败时能通知到人。
- 声明数据卷或数据迁移时，工具必须具备数据回滚能力。
- 自动执行不能跳过任何部署前门禁。

## 例外与边界
- 条件不满足时只能改为所有者逐次批准，不能退化为无告警的自动执行。

## 可观察验收
- 缺少告警去处或数据回滚能力的自动目标在配置阶段被拒绝，且不会被执行。

## 适用范围与版本
配置为自动审批的部署目标

# 历史要点与验收编号退役

## 业务目标
保证编号在历史分析中持续可回查，避免重排导致指代错乱

## 用户与角色
- 产品 Agent
- 运行时规格校验

## 触发与前提
重新分析导致要点或验收项新增、删除、重排

## 预期行为
退役编号集合持续保留，新条目分配未使用过的编号。

## 业务规则
- 历史用过的编号不得重新分配
- 退役判断覆盖删除与重排
- 已退役编号仍可在历史分析中回查

## 例外与边界
（无）

## 可观察验收
- 删除或重排条目后新增条目不会复用旧编号
- 历史编号在分析记录中仍可回查

## 适用范围与版本
需求说明的业务要点与验收项编号，2026-11 版本

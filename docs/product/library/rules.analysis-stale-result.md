# 迟到分析结果只留审计

## 业务目标
防止过期结论覆盖最新业务事实或触发错误推进

## 用户与角色
- 产品 Agent
- 运行时协调器

## 触发与前提
模型返回时需求版本已变化、需求已停止或取消、或已有分析结论

## 预期行为
结果写入 stale 尝试与轨迹仅作审计，需求状态、系统准入与业务背景保持不变。

## 业务规则
- 迟到结果不得更新需求状态与系统准入
- 迟到结果不得写入正式业务背景
- stale 不能当作独立错误码自动重试

## 例外与边界
- 需求已有结论时新返回同样按迟到结果处理

## 可观察验收
- 迟到返回不会改变需求的当前状态或准入结论
- 历史中可查到 stale 尝试及其轨迹

## 适用范围与版本
产品分析的并发与迟到返回，2026-11 版本

# 运维只操作登记的资源、检查与动作

## 业务目标
限制运维影响面，让自动处置只发生在已登记且可复核的范围内

## 用户与角色
- 运维 Agent（仅只读与建议）
- 主控（校验与执行）
- 所有者（批准非自动处置）

## 触发与前提
检查失败或主动监控发现问题时

## 预期行为
系统按签名归并事件，按目录授权执行一次登记动作，再以登记检查复核是否恢复；未恢复时按事实收口并生成关联修复需求。

## 业务规则
- 运维 Agent 只能读已登记制品与日志尾部，不能执行检查或动作、不能改文件、不能批准或验收
- 参数只能取目录允许值，动作不得跨资源
- 每个事件最多执行一次登记动作，失败或中断后不自动尝试第二种动作
- 恢复检查以退出码 0 为通过，超时不算通过
- 写未登记的监控提供方在装载时直接失败，可配置不等于已支持
- 恢复与永久修复分离：恢复通过只表示恢复检查通过，修复需求仍走正常流程

## 例外与边界
- 动作超时或宿主中断时按事实标为失败或中断，事件收口为未解决，不进入结果未知状态
- 等待所有者决定超时不是批准

## 可观察验收
- 未登记资源或动作不会被执行，事件停在待决定并说明原因
- 恢复状态只有在登记检查返回通过后才显示为已恢复

## 适用范围与版本
运维 Agent 与主控的处置流程，2026-11 版本

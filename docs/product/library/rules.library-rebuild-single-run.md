# 需求库重建是一次点击的单轮自动运行

## 业务目标
让存量项目不必逐条填写、逐条确认即可得到可核对的需求库参考条目

## 用户与角色
- 项目用户（发起与取消）
- 产品 Agent（执行取证与提炼）
- 系统（调度与发布）

## 触发与前提
用户在产品页点击「重建需求库」

## 预期行为
系统自动发现可用材料与业务主题，在后台分批取证与提炼，页面显示阶段、批次与材料数；完成后显示草案、冲突与未决摘要。

## 业务规则
- 同项目同一时间只允许一轮重建运行
- 运行中重复点击返回当前运行的进度，不新开一轮
- 生成结果不需要用户填写场景、再次确认扫描或逐条确认参考条目
- 取消状态以任务实际停止为准，不以点击取消为准

## 例外与边界
- 预算耗尽或部分证据不可用时按实际范围报告部分完成，并保留未覆盖的原条目
- 运行失败或发布前取消时，保留上一次可用库和本轮记录

## 可观察验收
- 点击一次后页面出现进度与批次，不再要求用户逐条确认扫描结果
- 运行中重复点击返回同一运行的进度
- 取消后页面显示实际停止状态，原需求库仍可查看

## 适用范围与版本
已绑定工作区项目的天工「产品」页，2026-11 版本

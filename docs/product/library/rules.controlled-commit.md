# 受控提交只整合本需求候选

## 业务目标
把验证过的需求候选以可追溯、不外溢的方式落到真实项目

## 用户与角色
- 运行时受控提交
- 研发 Agent
- 测试 Agent

## 触发与前提
独立测试或自验通过，且真实项目干净、基线一致

## 预期行为
只整合本需求候选并运行提交检查，创建本地提交并记录身份；后续发布与部署另行授权。

## 业务规则
- 只整合本需求候选
- 运行配置的提交检查
- 不 push、不打 tag、不递增版本
- 不混合其他在途改动

## 例外与边界
- 真实项目不干净或基线不一致时不创建提交
- 临时快照基线提交不是产品提交

## 可观察验收
- 受控提交只包含本需求候选内容
- 提交后没有 push、tag 或版本递增动作

## 适用范围与版本
测试通过后的受控提交，2026-11 版本

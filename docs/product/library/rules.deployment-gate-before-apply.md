# 部署前门禁必须全部满足

## 业务目标
让部署只接受已经完整验证并验收过的同一份候选。

## 用户与角色
- 所有者
- 主控
- 运维 Agent

## 触发与前提
部署意图进入执行阶段之前

## 预期行为
系统逐项校验门禁；任一项不满足则拒绝或停在等待批准，并说明不满足项。

## 业务规则
- 需求版本、停止状态与受控提交必须先满足。
- 候选摘要必须等于验证与业务终审绑定的摘要。
- 候选、任务包或需求修订后，旧验收自动失效。
- 自动审批目标不能以系统判定代替所需的人类验收。
- 等待批准期间依据变化时重新校验，复核失败不执行。

## 例外与边界
- 门禁不满足时保留部署意图但不执行，可重新提议。
- 自动审批目标由目标配置授权，减少逐次批准但不降低门槛。

## 可观察验收
- 验收后候选被重新构建时，原部署请求被拒绝并提示验收已失效。

## 适用范围与版本
所有部署目标；人类验收仅对需要所有者批准的目标必需

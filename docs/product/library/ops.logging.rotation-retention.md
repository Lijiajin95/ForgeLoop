# 日志轮转保留历史

## 业务目标
避免日志无限增长的同时保留可追溯历史

## 用户与角色
- 运维人员
- 插件运行时

## 触发与前提
当前日志达到配置的大小阈值时

## 预期行为
系统将当前日志改名为带 UTC 日期的历史日志；同一天再次轮转时追加连续序号；改名时先探测空闲名称；不删除、不覆盖既有历史；轮转失败仍继续追加当前日志；阈值为零表示不轮转。

## 业务规则
- 轮转后的历史日志必须保留，不得删除或覆盖。
- 同一天多次轮转的文件名必须可区分且连续。
- 轮转失败不得阻断后续日志写入。
- 阈值为零时明确表示不轮转。

## 例外与边界
- 同一天轮转次数很多时，序号持续增长。
- 磁盘或重命名失败时仍继续写入当前日志。

## 可观察验收
- 达到阈值后，历史日志仍可读取且未被覆盖。
- 同一天多次轮转后，历史日志名称可区分。

## 适用范围与版本
ForgeLoop 插件运行日志，2026-11 版本

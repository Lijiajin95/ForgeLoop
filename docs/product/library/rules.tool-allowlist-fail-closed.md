# 工具白名单不可执行时拒绝运行

## 业务目标
确保工具白名单在任何情况下都不被静默降级，保障运行隔离可信。

## 用户与角色
- 运行发起方
- 宿主环境维护者
- 安全与审计人员

## 触发与前提
以指定工具白名单启动受限运行时，或宿主缺少工具限制能力时。

## 预期行为
系统应在无法执行工具限制时直接拒绝运行并明确失败；能够执行时，白名单之外的调用一律被拒绝。

## 业务规则
- 缺少工具限制服务或工具服务时，受限运行应被拒绝，不得降级为无限制运行。
- 白名单之外的工具调用一律拒绝。
- 未提供白名单时，应拒绝全部工具调用。

## 例外与边界
- 宿主能力缺失属于拒绝路径，不视为可继续运行的警告。

## 可观察验收
- 在无法限制工具的环境中发起受限运行，用户可观察到运行被拒绝而非照常执行。
- 在受限运行中，用户可观察到白名单以外的工具调用被拒绝。

## 适用范围与版本
受限工具运行的宿主执行环境，2026-11 版本

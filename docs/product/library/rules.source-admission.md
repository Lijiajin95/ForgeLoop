# 来源放开与系统准入不是批准

## 业务目标
在保留完整来源审计的前提下不阻塞合理输入，同时不把准入伪装成人类批准

## 用户与角色
- 业务用户
- 模型工具
- 运维事件
- 运行时系统准入

## 触发与前提
任一非空来源提交需求或问题

## 预期行为
系统准入按确定性规则判定并单独落库；来源前缀与提交者完整记录，供审计与自主率统计。

## 业务规则
- 来源可信不等于动作授权
- 部署、发布与业务例外仍需独立授权
- 需要收紧时显式关闭任何来源并维护可信来源

## 例外与边界
- 系统准入未通过时需求不进入研发

## 可观察验收
- 任意非空来源提交都能进入系统准入并留下来源记录
- 系统准入记录不会伪装成所有者批准

## 适用范围与版本
需求进入系统的来源准入，2026-11 版本

# 本机自动化凭据只用于只读页面核对

## 业务目标
在不扩大授权的前提下完成部署后的只读冒烟核对

## 用户与角色
- 核对执行者
- 所有者（权限来源）

## 触发与前提
需要对已部署页面做只读核对时

## 预期行为
按与浏览器登录相同的格式派生绑定 Host 的 Cookie，写入受保护的本地缓存目录；脚本不打印密钥或 Cookie；冒烟进入会话页面并核对页脚运行版本。

## 业务规则
- 凭据只用于只读检查，不授予部署、批准或推进权限
- 凭据默认有效期有限且可配置上限，缓存目录与文件权限受保护，且不进入版本库
- 凭据文件不得复制到仓库、工单或聊天
- 删除本地文件只移除副本，需要撤销全部会话时应轮换服务端签名凭据并重启

## 例外与边界
- 命令行未携带登录态直接访问时得到拒绝，属于预期行为
- 冒烟只覆盖首页、看板端点、会话视图与页脚身份，不覆盖全部交互或人工验收

## 可观察验收
- 未携带登录态的访问被拒绝，带凭据的核对可返回页面状态与运行身份
- 凭证文件不出现在仓库或候选包中

## 适用范围与版本
自部署后的页面核对，2026-11 版本

# 一个需求绑定一个研发会话与固定工作区

## 业务目标
让同一需求跨任务保留连续代码上下文，并让会话归属可追溯

## 用户与角色
- 主控 Agent
- 研发 Agent
- 运行时协调器

## 触发与前提
需求进入研发，或同一需求出现后续任务与修复

## 预期行为
绑定记录需求版本、会话、工作区、基线与选择理由；复用会话时在原绑定上更新；一轮研发结束由同一会话产出会话总结。

## 业务规则
- 会话绑定一个固定研发工作区
- 同一需求后续工作回到原会话
- 会话不因任务结束而关闭或删除
- 绑定缺失时不能凭空断定会话属于该需求

## 例外与边界
- 测试会话是一次性会话，不按研发会话复用

## 可观察验收
- 同一需求的后续任务回到原会话与原工作区
- 任务结束后会话与工作区仍可查询和复用

## 适用范围与版本
研发会话与工作区，2026-11 版本

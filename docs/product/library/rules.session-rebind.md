# 会话不可用时改派并保留旧记录

## 业务目标
让会话失效时有可见、可追溯的替代路径，同时保留现场

## 用户与角色
- 主控 Agent
- 运行时协调器
- 研发 Agent

## 触发与前提
选中或已绑定会话在需要投入时不可用，且无备选会话可用

## 预期行为
按备选顺序尝试；全部不可用时改派新会话并更新绑定，写入原因，旧会话记录与工作区保留。

## 业务规则
- 改派原因写入绑定
- 旧会话记录与工作区保留
- 不静默换会话，也不冒充恢复

## 例外与边界
- 有备选会话时优先按备选顺序换用而不是直接改派

## 可观察验收
- 改派后绑定中能看到原因与新会话
- 旧会话记录与工作区仍保留可查

## 适用范围与版本
研发会话改派，2026-11 版本

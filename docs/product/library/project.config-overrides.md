# 项目可覆盖提交检查、部署与运维配置

## 业务目标
让不同项目使用各自的提交检查、部署与运维规则，同时保持全局配置作为兜底

## 用户与角色
- 项目所有者
- 项目维护人员

## 触发与前提
项目配置中声明提交检查、部署或运维字段

## 预期行为
系统按一层合并项目配置与全局配置，项目只覆盖自己声明的字段，未声明字段继续使用全局值。

## 业务规则
- 项目配置按一层合并，项目只覆盖自己声明的字段。
- 未声明的字段与数组沿用全局配置。
- 所有者、代理、记录根、项目标识与项目路径不允许项目级覆盖。

## 例外与边界
- 声明了受限键也不作为项目级配置生效。

## 可观察验收
- 项目声明提交检查命令后，该项目的检查使用项目值，其他项目仍使用全局值。
- 项目未声明的部署字段保持全局值。

## 适用范围与版本
项目级配置；全局配置仍为默认来源

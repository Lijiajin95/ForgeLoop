# 同一项目同时只允许一轮重建

## 业务目标
防止并发重建互相覆盖，并让所有者能安全中止未完成的重建

## 用户与角色
- 项目所有者
- 需求分析人员

## 触发与前提
所有者发起或取消某项目的重建

## 预期行为
系统对同一项目维持至多一个进行中的轮次，重复发起返回冲突；取消时保留已发布内容并停止后续发布。

## 业务规则
- 同一项目最多存在一个进行中的重建轮次。
- 已有进行中轮次时，再次发起返回冲突，不启动新轮次。
- 取消只停止尚未发布的部分，已发布内容保留。
- 运行记录包含发起者与来源，所有者动作可回查。
- 查询不存在的运行返回未找到。

## 例外与边界
- 重复发起：拒绝并提示已有运行。
- 取消后重新发起：按新一轮处理，已发布内容不自动回滚。

## 可观察验收
- 第二次发起同一项目的重建会被拒绝，并提示已有运行。
- 取消后运行状态可查，已发布内容不被破坏。

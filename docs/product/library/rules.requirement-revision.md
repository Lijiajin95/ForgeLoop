# 需求修订先停现场再重规划

## 业务目标
避免在旧版本上继续执行已失效的范围，同时保留历史版本与材料可追溯

## 用户与角色
- 业务用户
- 运行时协调器
- 研发 Agent

## 触发与前提
需求提交新修订并成为当前版本

## 预期行为
受影响执行先停止并保存现场，随后按新版本重规划派发；历史版本保留，旧准入与批准不被沿用。

## 业务规则
- 修订生效后先停止受影响执行并保存、核对现场
- 已有材料经适用性核对可复用
- 新修订不覆盖历史
- 旧准入与批准不能用于新版本

## 例外与边界
- 影响范围不明时扩大暂停范围

## 可观察验收
- 修订后受影响执行先停止并保存现场再继续
- 新版本不会沿用旧版本的准入或批准记录

## 适用范围与版本
需求版本修订与在途执行，2026-11 版本

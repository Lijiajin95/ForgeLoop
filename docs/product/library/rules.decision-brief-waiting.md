# 客户决定材料与等待行为

## 业务目标
让客户在不了解技术细节时也能作出有依据的取舍，且等待不被误当作批准

## 用户与角色
- 业务用户（所有者）
- 产品 Agent
- 运行时协调器

## 触发与前提
系统请求客户决定，或处于等待客户决定期间

## 预期行为
决定请求呈现多方案比较与推荐理由；等待期执行已授权止损措施，待决动作及其依赖暂停，确认无关的工作继续。

## 业务规则
- 不为凑选项虚构可行方案
- 等待超时不等于批准
- 确认无关的工作继续

## 例外与边界
- 无法证明可行性或缺少估算依据的部分必须标注

## 可观察验收
- 客户决定请求中能看到多方案比较与推荐理由
- 等待期间待决动作保持暂停，超时后不会自动继续

## 适用范围与版本
客户决定请求与等待期，2026-11 版本

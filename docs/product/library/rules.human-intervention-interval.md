# 人工处理区间按人去重且缺时长标注未知

## 业务目标
让“人类实际投入了多少”可被核对，而不是把等待或查看也算成介入

## 用户与角色
- 业务用户（所有者）
- 运行时介入记录
- 看板

## 触发与前提
所有者实际处理某个介入事项，或系统聚合人工介入耗时

## 预期行为
区间单独记录并校验需求存在、执行者与原因非空、结束不早于开始且不晚于当前时刻；聚合时同一人重叠区间只计一次；缺时长按“时长未知”展示。

## 业务规则
- 只有可观测的实际处理时段才算介入
- 同一人的重叠区间聚合时只计一次
- 人工介入率分母保留失败、卡住与未完成项
- 同一需求多次介入在介入率中只计一次

## 例外与边界
- 等待回复与日常查看进度不算介入
- 缺时长按“时长未知”展示，不虚构数值
- 单次区间有上限

## 可观察验收
- 度量中能看到人工处理区间与按人去重后的介入耗时
- 缺时长的介入显示“时长未知”而不是被补成估计值

## 适用范围与版本
人工介入记录与人工介入率，2026-11 版本

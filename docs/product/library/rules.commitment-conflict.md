# 承诺冲突暂停准入并交客户取舍

## 业务目标
让客户决定范围取舍，防止新输入或 Agent 提议静默压过既有承诺

## 用户与角色
- 业务用户（所有者）
- 产品 Agent
- 运行时系统准入

## 触发与前提
新输入与已有需求承诺无法同时满足

## 预期行为
分析列出承诺冲突并以待决定事项暂停系统准入，直到所有者给出取舍。

## 业务规则
- 冲突必须引用现有需求与具体冲突点
- 至少给出两种取舍方案供选择
- 系统不得自动选择冲突中的一方

## 例外与边界
- 执行层的文件修改、任务依赖与排期竞争不自动构成业务冲突

## 可观察验收
- 出现承诺冲突时需求暂停准入并展示取舍选项
- 系统不会自行选择冲突中的一方继续推进

## 适用范围与版本
所有阶段的新需求与已有承诺，2026-11 版本

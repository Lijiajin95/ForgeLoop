# 交付度量三项指标口径

## 业务目标
让交付效率和可用率不被选择性剔除坏样本而失真

## 用户与角色
- 业务用户
- 运行时度量读取
- 看板

## 触发与前提
按项目与受理日期查询交付度量，或指定过去截止时点回看

## 预期行为
度量快照只读，按截止时点计算交付率与用时；未完成项单独列出已等待时长，不与已完成项混算。

## 业务规则
- 交付率分母不剔除失败与未完成
- 交付必须绑定当前需求版本且可用时间不晚于截止时点
- 截止时点可回看但不接受未来时点

## 例外与边界
- 验收指纹无法复核的 owner 目标不计入可用交付

## 可观察验收
- 度量视图或接口返回可安装交付率、样本数与分位数
- 未完成项单独显示已等待时长而不混入已完成用时

## 适用范围与版本
交付度量快照与看板读取，2026-11 版本
